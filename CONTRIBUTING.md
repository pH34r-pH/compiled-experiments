# Contributing

Compiled Experiments are publication artifacts, not a general scratch area.

A contribution should include:

- a stable experiment ID;
- human-readable protocol/replay instructions;
- a source recipe and RO-Crate metadata;
- immutable upstream dependency identities;
- a canonical compiled artifact with SHA-256;
- Compiler integrity receipts;
- a scientific replay/decision receipt;
- licensing/provenance sufficient for public redistribution.

Do not add secrets, private paths, transient runner credentials, or unreviewed model/data redistribution.

Repository-authored material is Apache-2.0 unless a nested artifact states otherwise.
